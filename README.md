# Sistema de Chamados de Suporte

Sistema web para gerenciamento de chamados de suporte, desenvolvido como projeto de estudo e portfólio de desenvolvimento Full Stack.

> Projeto em desenvolvimento.

## Sobre o projeto

A aplicação permitirá que funcionários abram chamados e acompanhem o atendimento de seus problemas.

Atendentes poderão visualizar a fila de suporte, assumir chamados, adicionar comentários e registrar soluções.

Administradores poderão gerenciar usuários, categorias e acompanhar informações do sistema.

## Funcionalidades

* Login e controle de acesso
* Criação de chamados
* Listagem e acompanhamento de chamados
* Atribuição de atendentes
* Comentários
* Controle de prioridade e status
* Histórico de alterações
* Reabertura de chamados
* Painel de indicadores
